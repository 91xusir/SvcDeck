探针

探针是最终真相；失败连续超过阈值才判定 DOWN
0 表示接受 2xx/3xx。
进程探针按 runtime_state 中记录的 pid + 创建时间 + exe 路径做三重校验；pid 失效时按唯一 exe 路径找回进程。适合没有端口或不便做 HTTP 检查的服务。

保活

连续 DOWN 后按退避序列重启；超上限熔断
0 表示关闭自动保活（只探活，不自动拉起）。
例如 1,2,5,30；超过末尾后按最后一档封顶。
